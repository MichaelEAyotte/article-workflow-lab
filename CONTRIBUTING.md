## Checks

Use Node.js 22 or newer and run:

```text
npm test
npm run demo
```

Keep examples fictional and source behavior covered by focused tests. Document any change to the utility boundaries, and preserve the distinction between this extracted subset and the private production website. There is no deployment workflow in this repository.
